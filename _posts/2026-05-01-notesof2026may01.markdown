-1-

เราลองใช้ Claude Cowork กับ Claude Code มาสามวัน  รู้สึกช็อคที่ว่ามันทำได้เกือบทุกอย่าง มันหาเอกสารในเครื่องเราแล้วรวบรวมให้เรียบร้อยได้ มันอ่าน Bank Statement แล้วทำบัญชีรายรับรายจ่าย ทำงบประมาณส่วนบุคคลได้ มันรวมข้อมูลใน portfolio จาก broker ต่างๆ มาแล้วสรุป pnl ได้  และทั้งหมดนี้เราใช้แค่โมเดลความสามารถระดับ “ปานกลาง” ของ Anthropic ที่ชื่อว่า Sonnet เท่านั้น ยังไม่ได้ลองใช้ Opus เลย 

เรารู้สึกว่านี่แหล่ะคือ use case ของ AI ที่แท้จริง นั่นคือช่วยเราทำเรื่องที่น่าเบื่อ แล้วมอบเวลาให้เราทำในสิ่งที่เป็น high level ยิ่งขึ้น ภาพกว้างระดับยุทธศาสตร์มากขึ้น  ไม่ใช่เอาไว้ generate ภาพ ข้อความ อะไรก็ไม่รู้ออกมาเต็ม feed social media

-2- 

พูดถึงการ generate ภาพและข้อความ เรารู้สึกว่า comment, post ส่วนใหญ่ใน instagram, reddit (เราเลิกเล่น facebook และ twitter ไปแล้ว) กลายเป็น ai generated content ไปกันหมดแล้ว  หลายคนใช้ Claude Code สร้าง schedule job ให้ ai โพส content เสร่อๆ controversial เรียกยอด engagement เรื่อยๆ ทุกครึ่งชั่วโมง สร้างรายได้เสริม  สิ่งเหล่านี้ทำให้เราหดหู่ รู้สึกว่าทุกสิ่งคือของปลอม และถูกหลอกตลอดเวลา 

-3-

โดยตั้งใจหรือไม่ตั้งใจ ทักษะนักกฎหมายได้กลายมาเป็นทักษะที่ต้องใช้มากที่สุดเวลา vibe coding หลักการที่คุ้นเคยเช่นเขียนภาษาคนให้รู้เรื่อง ชัดเจนไม่คลุมเครือ ปฏิบัติได้จริง การวางประเด็น กำหนดผลลัพธ์ เรียบเรียงข้อเขียนให้เป็นหมวดหมู่ เป็นเหตุเป็นผล ทั้งหมดนี้เป็นประโยชน์อย่างมากเวลาเขียนคำสั่งให้ agentic AI เรานึกถึงปาฐกถาของสตีฟ จ๊อบเรื่อง connecting the dot ที่แกเล่าเรื่องที่แกเคยฝึกออกแบบตัวอักษรบนกล่องเก็บของ แล้วทักษะนั้นก็กลายมาเป็นพื้นฐานการออกแบบ UI mac os ในอนาคตแบบไม่ได้ตั้งใจ  ทักษะใดๆ บนโลกนี้ถ้ามีเวลา ถ้าไม่เหลือบ่ากว่าแรง ก็ควรเรียนไปโดยไม่ต้องคิดว่าโตไปจะเอาไปใช้ทำอะไร เพราะไม่มีใครรู้ (โดยเฉพาะในช่วงเวลานี้) ว่าเราจะต้องใช้ทักษะอะไรในอนาคตอีกบ้าง 

-4-

ลองทำ Contrast therapy (ice bath สลับแช่น้ำอุ่น) มาได้สามสัปดาห์แล้ว สิ่งที่เกิดขึ้นคือ เรารู้สึกเป็นคนใจเย็นมีสติขึ้นสองสามวันหลังทำ ทนเรื่องโง่ๆ หัวควยๆ ได้นิ่งขึ้นโดยไม่กระทบสมาธิ สามารถตั้งสติทำงานของตัวเองต่อไปได้ แต่อย่างไรก็ดี effect มันก็เริ่มหายไปหลังจาก 3-4 วัน ต้องกลับไปทำใหม่

เรื่องแปลกตอนแช่ ice bath คือ ช่วงแรกๆ อยู่ได้ไม่เกิน 15 วิ เพราะเจ็บตีนมาก อ่านมาว่าเพราะหนังฝ่าตีนไม่มีตัวป้องกัน ทำให้เกิดอาการเย็นจนเจ็บและจะทำให้ทนไม่ไหวไปก่อน  เทคนิกที่เราใช้หลังๆ คือตั้งสมาธิกับลมหายใจแล้วลองเมินเฉยกับสัญญาณเจ็บสักพัก จนครบ 45 วิ อยู่ดีๆ มันก็เลิกเจ็บไปเลย เหมือนสายโทรเข้าที่เราไม่รับ อยู่ดีๆ มันก็เลิกส่งเสียงรบกวนไปเอง
